# Best Practices for GenAI in Research

This is a community-maintained collection of:
- Practical guidelines for using GenAI in research  
- Documented workflows and use cases  
- Ethical considerations and potential pitfalls  
- Evolving recommendations for transparency, reproducibility, and reporting  

This repository is meant to **grow over time**, shaped by contributions from researchers, students, and practitioners across the field.

## How to Contribute?

We use a discussion-first workflow aligned with open science values.

### 1. Open an Issue  
Use the **Issues** tab to propose:
- New best practices  
- Revisions to existing guidelines  
- Ethical or methodological questions  
- Case examples or demonstrations  
- Tools or workflows to document  

Include:
- A clear description of your suggestion  
- Why it matters  
- Any references or examples (optional)

### 2. Discuss  
Community members and maintainers will:
- Ask clarifying questions  
- Offer feedback  
- Propose refinements  
- Assess scope and relevance  

### 3. Merge
If the idea is accepted, the maintainers will add it to the collection.

---

## Contribution Principles

- **Transparency:** Every change begins with an issue.
- **Community Knowledge:** Multiple perspectives strengthen the guidance.
- **Respect:** Support constructive, evidence-based dialogue.
- **Practical Value:** Contributions should help researchers navigate GenAI responsibly.
